# OV Prakash Personal Website

## Publish using GitHub Pages
1. Create a GitHub repository, for example: `ovprakash-website`.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, select `Deploy from a branch`.
5. Choose branch `main` and folder `/root`, then Save.
6. GitHub will provide your website URL.

## Connect your own domain
1. In GitHub Settings > Pages, enter your domain under Custom domain.
2. Update your domain's DNS records with your domain provider according to the GitHub Pages instructions shown there.
3. Enable Enforce HTTPS after DNS verification succeeds.

## Important customization
Replace `your-email@example.com` in `index.html` with your real email address.
You can also replace the OV initials profile block with a professional photo later.
